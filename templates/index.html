Operating Systems Concepts & Project Architecture

Theoretical foundation for the OS College Mini-Project Viva

1. Threads & Mutex Locks

Threads represent concurrent paths of execution within the process. Shared resources (R1, R2, R3) are guarded by mutual exclusion (Mutex) locks to prevent race conditions during critical section access.

2. Wait-for Graph (WFG)

A reduced form of the Resource Allocation Graph (RAG) where resource nodes are folded into directed edges between threads. Edge Ti → Tj signifies Ti is waiting for a lock held by Tj.

3. Coffman Deadlock Conditions

Deadlock requires four simultaneous conditions: (1) Mutual Exclusion, (2) Hold & Wait, (3) No Preemption, and (4) Circular Wait. Under single-instance resource constraints, a cycle in the WFG is a necessary and sufficient condition for deadlock.

4. Cycle Detection Algorithm

We apply Depth-First Search (DFS) on the dynamic directed graph with recursion stack tracking. Time complexity is O(V + E), identifying exact circular dependency loops.

5. Safe Cooperative Recovery

Instead of abruptly killing OS threads (which can corrupt program state and leave orphaned locks), the detector cancels a selected victim thread cooperatively via atomic flags and triggers safe resource preemption.

6. Victim Selection Policies

The dashboard implements: (1) Fewest Resources Policy (terminates the thread holding minimal locks to reduce lost computation), and (2) Manual Selection (operator chosen).
